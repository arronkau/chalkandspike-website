# Chalk & Spike

## Deployment

1. Unzip the archive. Upload its contents to the root of a static web host, keeping the `assets/` directory intact. The host should serve `index.html` at `/`. The site has no build step or server dependencies.
2. Add `chalkandspike.com` as the host’s custom domain. Use the DNS records your host supplies and enable HTTPS. Preserve any existing mail records.
3. Open `https://chalkandspike.com/` and check the artwork and email link. Scroll down for the template credit. The link opens the visitor’s mail app. Mailbox delivery is managed separately.

Open `index.html` locally for a preview. Edit the page text in `index.html` and the palette in `assets/css/site.css`.
